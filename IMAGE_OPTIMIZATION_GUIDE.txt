2. ДОБАВИТЬ В app.py (после импортов):

   from PIL import Image
   from io import BytesIO
   import requests
   
   def optimize_image(image_url, quality=60, max_width=500):
       """Скачивает и сжимает изображение"""
       try:
           response = requests.get(image_url, timeout=5)
           img = Image.open(BytesIO(response.content))
           
           # Сжатие размера
           if img.width > max_width:
               ratio = max_width / img.width
               new_height = int(img.height * ratio)
               img = img.resize((max_width, new_height), Image.Resampling.LANCZOS)
           
           # Оптимизация формата (JPEG или WebP)
           output = BytesIO()
           img_format = 'WEBP' if 'webp' in image_url.lower() else 'JPEG'
           img.save(output, format=img_format, quality=quality, optimize=True)
           output.seek(0)
           return output.getvalue()
       except Exception as e:
           logging.error(f"Ошибка оптимизации: {e}")
           return None

ПАРАМЕТРЫ ОПТИМИЗАЦИИ:
====================
- Качество: 60% (минимум для видео миниатюр)
- Максимальный размер: 500px ширина
- Формат: WebP (если поддерживается), иначе JPEG
- Кэш: 30 дней для миниатюр
- GZIP: Включить для всех текстовых ответов

ОЖИДАЕМОЕ СОКРАЩЕНИЕ ТРАФИКА:
==============================
✓ WebP формат: -25-35% от размера JPEG
✓ Сжатие качества: -40-50% от оригинала
✓ Ресайз изображений: -60-70% от оригинала
✓ Удаление анимаций: -10% от CSS
✓ GZIP сжатие JS/CSS: -70% от размера
✓ Lazy loading: Загрузка только видимых изображений

ИТОГО: Примерно на 70-80% сократится трафик изображений!
